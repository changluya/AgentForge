# About AgentForge

AgentForge is an open-source Java agent framework built from low-level LLM abstractions upward. It establishes provider-neutral model APIs first, then builds Context, Memory, Tools, Reasoning and Agent Runtime capabilities layer by layer.

> **Forge Intelligence into Action.**

Upper layers depend on AgentForge's `ChatModel` and `StreamingChatModel` contracts instead of a vendor SDK.
